# 工作台使用与验证指南

这个项目是本地可复现的企业 IT 支持演示。默认使用 Mock 模型和确定性向量编码，不需要外部模型密钥；员工、工单和知识文章都是虚构样本。它能展示资料检索、带来源的回答、按本人范围查单、确认后建单和安全转人工，但不连接真实企业账号或工单系统。

默认 Mock 模式会把首条命中资料的原文片段和引用编号放进主回答，方便核对内容；它不具备真实模型的归纳能力。其余命中片段会在“本次检索证据”中展示。

## 先认识页面上的内容

- **演示身份**：`u-001 / c-001` 是员工甲及其会话，`u-002 / c-002` 是员工乙及其会话。二人都是 `employee`。用户标识用于过滤可见知识和工单；它只是本地模拟身份，不是正式认证。
- **知识资料**：源文件在 [`data/knowledge`](../data/knowledge) 中，共 32 篇 Markdown。导入后会形成 128 个检索片段。默认员工可见 30 篇；`access-review.md` 和 `temporary-admin-access.md` 标为 `support`，不会对员工展示或参与其检索。
- **工单数据**：种子配置在 [`data/tickets/seed_tickets.json`](../data/tickets/seed_tickets.json)，会生成 `IT-2026-0001` 到 `IT-2026-0100` 共 100 张工单。两个模拟用户各自只能查询自己的工单。
- **本次检索证据**：显示本次检索返回、提供给回答生成的片段、文章标题和源文件名。同一文章可能命中多段；这些片段不代表回答逐条采纳了其中的全部内容。点击“查看原文”可以在资料库核对完整文章。
- **处理过程**：折叠区域显示 Agent 经过的节点；回答、引用、工单或转人工原因优先展示。

知识文章覆盖 VPN、Wi-Fi、有线网络、DNS、账号与 MFA、共享目录、打印机、会议音频、显示器、设备、邮件、安全报告等主题。页面上的“已索引的知识资料”从当前数据库读取，检索框可按标题或文件名筛选，并能打开原文。

## 输入格式

对话框接受自然语言，不需要 JSON：

- **问知识**：写清故障现象、错误代码、影响范围和已尝试的操作，例如“公司 VPN 连不上时应该先检查什么？”
- **查工单**：写“查询工单 IT-2026-0001 的进度”。格式为 `IT-年份-至少四位流水号`。单独输入 `IT-2005-001` 缺少足够位数，也不属于演示工单。
- **建工单**：写“VPN 一直连接失败，请创建工单”。系统先给出草稿，只有核对并点击“确认并创建工单”后才写入。

工单优先级是影响程度，不是处理人：`low`（影响较小）、`medium`（影响个人工作）、`high`（关键工作受阻）、`critical`（大范围中断或重大风险）。这些是演示说明，没有配置真实 SLA 或自动派单。状态代码 `pending`、`in_progress`、`resolved`、`closed` 分别对应待分派、处理中、已解决待确认、已关闭。

## 四条可复现路径

| 路径 | 输入 | 期望看到 |
| --- | --- | --- |
| 知识回答 | `公司 VPN 连不上时应该先检查什么？` | `answered`，答案引用《VPN 连接故障处理》，可打开原文 |
| 本人查单 | `查询工单 IT-2026-0001 的进度` | `ticket_status`，员工甲看到 `pending` 和最新进展 |
| 确认建单 | `VPN 一直连接失败，请创建工单` | `awaiting_confirmation`，先出现草稿；确认后生成工单号 |
| 安全兜底 | `我桌上的未知型号量子终端出现紫色告警，怎么修？` | `handoff`，原因 `insufficient_evidence`，不编造处理步骤 |

页面顶部的案例按钮会把输入填入对话框，不会自动发送。发送后先看结果与引用，再按需要展开处理过程。

## 添加自己的知识资料

1. 在 `data/knowledge` 新建 UTF-8 Markdown 文件。文章应有 `version`、`access_level` 元数据，以及标题和“适用对象 / 前置条件 / 操作步骤 / 何时转人工”四个二级标题。
2. `access_level` 可为 `employee`、`support` 或 `admin`。不要在演示知识中放真实员工资料或密钥。
3. 在项目根目录运行 `docker compose exec api python /app/scripts/ingest_knowledge.py`。页面刷新后会从数据库显示新文章；若修改已有文章，请递增 `version`，再重新导入。
4. 删除资料文件后也运行同一条导入命令，再刷新页面。目录同步会停用并清理该文件的检索片段；仅删除磁盘文件不会即时更新已经建立的索引。

示例格式：

```markdown
---
version: "1.0"
access_level: employee
---

# VPN 连接故障处理

## 适用对象

使用公司设备连接 VPN 的员工。

## 前置条件

确认设备可以访问互联网。

## 操作步骤

记录错误码并重新打开客户端。

## 何时转人工

重复失败或出现证书错误时联系 IT 支持。
```

资料库只展示已成功导入、状态为 active 且当前演示身份有权限查看的文章。源文件与已索引版本不一致时，原文接口会提示重新导入，避免展示与检索内容不符的文件。
